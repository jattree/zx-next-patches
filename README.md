# ZX Spectrum Next conversions

Patches that turn your own copy of a classic game into an improved conversion for the
ZX Spectrum Next. Each game has its own folder with the patch, a README (the exact file you
need, how to apply the patch, the controls and what plays differently) and a changelog.

**No game data is included.** Every patch checks the file you give it and refuses anything but
the exact version it was made for.

| Game | Original | Folder | Version |
| --- | --- | --- | --- |
| Alex Kidd in Miracle World | Sega Master System, 1986 | [`alexkidd/`](alexkidd/) | 1.5 |

## Applying a patch

The patches are BPS files. Apply one in a browser with Rom Patcher JS
(https://www.marcrobledo.com/RomPatcher.js/) or with Floating IPS (Flips). Each game's README has
the details, including what to name the result.
